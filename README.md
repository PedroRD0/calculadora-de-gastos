# Calculadora de Gastos 💰

Esse é o meu primeiro projeto em Java e também o primeiro que desenvolvi do começo ao fim colocando em prática o que venho aprendendo.

## Sobre o projeto

Escolhi criar uma calculadora de gastos porque queria começar com algo simples, mas que resolvesse um problema real do dia a dia: saber quanto do salário realmente sobra depois das despesas do mês.

A primeira ideia era apenas informar o salário, adicionar alguns gastos e calcular o saldo. Conforme fui desenvolvendo e aprendendo coisas novas em Java, comecei a pensar em como poderia deixar o programa mais completo.

Adicionei a identificação do maior gasto, o cálculo da porcentagem do salário que sobrou ou foi ultrapassada e mensagens diferentes dependendo do resultado do mês. Também percebi que não fazia sentido aceitar valores negativos e implementei validações para que o programa peça o valor novamente quando isso acontecer.

Foi um projeto simples, mas importante para mim porque consegui sair dos exercícios isolados e usar o que estou estudando para construir algo funcionando de verdade.

## O que o programa faz

- Recebe o salário do usuário
- Registra gastos com aluguel, alimentação, estudo e lazer
- Calcula o total gasto e o saldo restante
- Mostra quanto do salário foi economizado ou ultrapassado em porcentagem
- Identifica qual foi o maior gasto
- Informa se o mês terminou com saldo positivo, negativo ou zerado
- Não permite valores negativos nas entradas

## O que pratiquei

Durante o desenvolvimento trabalhei principalmente com:

- Variáveis e tipos de dados
- `Scanner` para entrada de informações
- Operações matemáticas
- `if`, `else if` e `else`
- Operadores lógicos como `&&`
- Laços de repetição com `while`
- Validação de dados
- Formatação de valores com `printf`
- Git e GitHub para versionar a evolução do projeto
